# Historical documentation guide

The preserved guides `USER_GUIDE.md`, `RESULT_SCHEMA.md`, `FULL_STUDY_PROTOCOL.md`, `REPRODUCING_FULL_STUDY.md`, `METHODOLOGY.md` and `PILOT_README.md` describe the historical release, four-task cohort or separate pilot. Their original planning/status labels are historical. Use `REPRODUCING_ARRAY_REVISION.md`, `EXPANDED_STUDY.md` and `DATA_DICTIONARY.md` for the completed expanded dataset.

`ADDING_TASKS.md` and `EXTENSION_EXAMPLE.md` describe the retained TaskAdapter API and handwritten example. `EXTERNAL_CASES.md` describes the separately frozen Stripe/Seam illustration; its reported 54 records remain historical evidence. The unchanged external SDK lock is deliberately separate from the main evaluator lock. In particular, its recorded AnyIO version differs; do not merge the environments and call the resulting measurements the original records.
