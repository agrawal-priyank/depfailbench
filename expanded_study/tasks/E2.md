Task E2 Shipping-quote selection

Select POST /shipping/quote with JSON {destination: nonempty string up to 64 characters, weight_g: strict integer 1..100000}. Query GET /quotes with destination and weight_g parameters on the one injected dependency. It returns {quotes: [...]}. A valid option has quote_id: nonempty string, price_cents: nonnegative strict integer, currency: "USD", delivery_days: strict positive integer. Discard invalid individual options. Choose the smallest (price_cents, delivery_days, quote_id) tuple and return the complete selected option with 200. A valid empty list or no valid options returns 404. An invalid outer response or conflicting reuse of a quote_id returns 502; do not return a partial/fabricated quote. Identical duplicate options may be deduplicated. Public invalid input returns 422 without a downstream call. Store prices in integer cents to avoid floating comparison ambiguity.
