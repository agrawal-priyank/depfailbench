Task E7 Object upload

Implement POST /uploads/{object_key}, JSON content string, exact UTF-8 PUT to /objects/{object_key}, idempotent overwrite semantics and key/SHA-256 receipt validation. Return 200 only for the correct key and lowercase hexadecimal digest of the exact supplied bytes. Validate stored key/content independently. A lost acknowledgment permits an idempotent retry to the same key; altered content, wrong key or an unvalidated success receipt never passes.
