Task E8 User-preferences replacement

Select PUT /preferences/{user_id} with optional language in {en, es, fr} and email_notifications as a strict Boolean. Unknown public fields or invalid values return 422 before dependency work. Defaults are language="en" and email_notifications=true. Every request constructs the complete record from these defaults plus supplied values; omitted fields reset to defaults, rather than retain previous values. Send PUT /preferences/{user_id} with the complete preferences object. A receipt contains the same user_id and preferences; validate every required value before returning 200. Repeating the complete replacement leaves the same final record, including after acknowledgment loss. Inspect the dependency's saved record; a matching-looking response without correct stored state fails. Return 502 for a malformed/mismatched receipt and 503 for dependency unavailability or an unconfirmed write.
