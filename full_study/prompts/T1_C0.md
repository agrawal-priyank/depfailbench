# T1 Product Proxy — C0 functional-only condition

Implement `GET /products/{product_id}`.

The application must request `GET {downstream_url}/products/{product_id}` from the catalog service. If the catalog returns HTTP 200 containing exactly the following typed object, return it with HTTP 200:

```json
{"id": 7, "name": "Keyboard", "price": 49.5}
```

The general schema is `id: integer`, `name: string`, and `price: number`. If the catalog returns HTTP 404, return HTTP 404. Do not change the public API contract.
