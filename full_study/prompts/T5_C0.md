Implement POST /uploads/{object_key}. Accept JSON {"content": string}. Encode content as UTF-8 and PUT the exact bytes to {settings.downstream_url}/objects/{object_key}. The object store overwrites the same key idempotently. A successful receipt is JSON with key equal to object_key and sha256 equal to the lowercase hexadecimal SHA-256 of the bytes. Return HTTP 200 with {"key": object_key, "sha256": digest} only with a valid receipt. A failed or uncertain upload should return an HTTP error. Never write to a different key or change the supplied content. Use the injected transport. settings.timeout_s is the per-attempt timeout, settings.max_attempts the attempt limit, and settings.deadline_s the application deadline.
